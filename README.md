# Inner Peace

## Problem Statement
Mental stress and anxiety often go unnoticed until they become severe.

## Solution
Inner Peace is an AI-powered IoT-based mental wellness monitoring system that uses ESP32 and biosensors to monitor stress levels in real time.

## Components
- ESP32
- GSR Sensor
- Heart Rate Sensor
- Temperature Sensor
- OLED Display

## Features
- Real-time stress monitoring
- Health parameter tracking
- AI-based analysis
- Portable and low-cost design

## Future Scope
- Mobile app integration
- Cloud data storage
- Personalized wellness recommendations
